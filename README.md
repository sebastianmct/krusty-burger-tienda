## ¿Qué es esto?

Este proyecto es una tienda virtual de Krusty Burger, diseñada como una página estática con estilo cartoon y temático de la serie Los Simpsons. Incluye varias secciones como inicio, promociones, nosotros, contacto y registro, con una interfaz pensada para ser clara, colorida y funcional.

> 💡 *La idea fue crear una experiencia visual simple y dinámica para mostrar productos, promociones y la identidad del restaurante de una forma amigable y moderna.*

## Funcionalidades

- **Landing page principal** con presentación del restaurante y sus principales ofertas.
- **Sección de promociones** con cards visuales y destacados para productos y combos.
- **Página de nosotros** con contenido institucional y estilo temático.
- **Formulario de contacto** con estructura clara y diseño básico.
- **Formulario de registro** con estilo acorde al proyecto.
- **Sistema de navegación simple** entre las distintas páginas del sitio.
- **Diseño responsive básico** para visualización en distintos tamaños de pantalla.

## Inicio rápido

1. Clona el repositorio:

```bash
git clone https://github.com/sebastianmct/krusty-burger-tienda.git
cd krusty-burger-tienda
```

2. Abre cualquiera de los archivos HTML en el navegador, por ejemplo:

```bash
home.html
```

3. Si quieres ver el proyecto completo, navega entre las páginas del sitio desde el menú.
